# 🚀 GenAI Plus Full Stack

A full-stack web application built using modern technologies.

---

## 🛠 Tech Stack

### 🔹 Frontend
- React
- Vite
- SCSS

### 🔹 Backend
- Node.js
- Express.js
- MongoDB
- JWT Authentication

---

## 📁 Project Structure

GenAiplusFullStack/
├── frontend/ # React App
├── YT-GenAi/ # Backend API

## ⚙️ Installation & Setup

### 🔹 Backend
cd YT-GenAi
npm install
npm run dev


### 🔹 Frontend

cd frontend
npm install
npm run dev
